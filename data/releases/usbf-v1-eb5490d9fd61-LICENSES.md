# Source attribution and component terms

USBF has no blanket unrestricted license. Original source labels and component notices are retained within each spatial tile.

OSM and Microsoft-origin footprints retain ODbL 1.0 attribution and change notices. Google-origin and GBA-generated polygon components, and inherited GBA heights/variance, retain the GBA CC BY-NC 4.0 component terms. Combining components in a tile does not relabel them under one different license.

Sources and notices:
- GlobalBuildingAtlas: https://doi.org/10.5194/essd-17-6647-2025
- GBA component terms: https://tubvsig-so2sat-vm1.srv.mwn.de/terms_of_use.html
- OpenStreetMap contributors: https://www.openstreetmap.org/copyright
- Microsoft footprints: https://github.com/microsoft/GlobalMLBuildingFootprints
- Google Open Buildings: https://sites.research.google/open-buildings/
- ODbL 1.0: https://opendatacommons.org/licenses/odbl/1-0/
- CC BY-NC 4.0: https://creativecommons.org/licenses/by-nc/4.0/

Use the per-record component fields and upstream notices when selecting data. Cite the dataset URL, selected tiles and access date.
